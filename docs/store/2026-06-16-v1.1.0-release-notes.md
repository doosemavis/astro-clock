## Full changelog (internal reference — what actually shipped since the last upload)

**New features**
- **Dynamic onboarding walkthrough** — 5-slide first-run carousel (live sky, birth chart, time-travel demos) with a sign-up funnel; replayable from ☰ → "How it works".
- **Theme switcher** — Light / Dark / System, persisted across launches (☰ → Theme).

**Improvements**
- Password **show/hide** eye toggle on all password fields (linked across the new + confirm pair).
- **"Rate MoveStar"** button in the Account sheet → opens the Play Store listing.
- Header icons corrected: **hamburger (☰) opens the menu, the sign glyph opens Coordinates / Sign-in** (was reversed).
- Single app-wide **12/24-hour** control in Birth Details (removed the redundant per-view toggle).
- Save-to-Photos hidden for signed-out users; birth-form and header cleanups.
- Range big-three freezes at the start during playback; updates on pause/reset/end.

**Store listing (uploaded separately in Console, not part of the .aab)**
- New ASO title/short/full description + 6 art-directed screenshots.
